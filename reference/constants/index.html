BTC_LEGACY_XPUB_PATH​

const BTC_LEGACY_XPUB_PATH: "44'/0'/0'" = "44'/0'/0'"

Derivation path for Bitcoin legacy xpub (BIP44). Use with fetchAddressesByDerivationPath() and LatticeGetAddressesFlag.secp256k1Xpub

Example​

const xpub = await fetchAddressesByDerivationPath(BTC_LEGACY_XPUB_PATH, {
  flag: LatticeGetAddressesFlag.secp256k1Xpub
});
